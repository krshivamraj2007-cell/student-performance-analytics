# Student Performance Analytics

A data analytics project that analyzes student academic performance, attendance, and risk levels using Python, Pandas, PostgreSQL, SQL, and Streamlit.

## Features

- Synthetic student data generation
- Data cleaning and preprocessing with Pandas
- Data transformation and performance categorization
- PostgreSQL database integration
- SQL-based academic performance analysis
- Interactive Streamlit dashboard
- Department and semester filters
- Student search and performance categories
- Attendance and risk analysis
- Department performance ranking
- Dashboard insights and KPI metrics
- CSV report downloads

## Tech Stack

- Python
- Pandas
- PostgreSQL
- SQL
- Streamlit
- Git and GitHub
